# UI / UX Design System

## Visual Direction

Gunakan gaya learning SaaS modern:

- clean;
- profesional;
- elegan;
- tidak flat/monoton;
- tidak terlalu colorful;
- 1 warna utama + warna status seperlunya;
- tanpa gradient berlebihan;
- tanpa glow;
- tanpa shadow besar;
- radius kecil/moderat;
- whitespace cukup;
- typography mudah dibaca;
- mobile-first;
- desktop nyaman;
- keyboard-friendly.

## Consistency

Gunakan satu design system untuk seluruh halaman:

- button
- input
- option
- card
- badge
- modal
- alert
- navigation
- drawer

Jangan membuat tombol atau input style berbeda hanya karena halaman berbeda.

## Micro-interaction

Animasi ringan diperbolehkan untuk:

- state change;
- drawer/modal;
- feedback answer;
- navigation;
- progress.

Jangan mengorbankan performa atau accessibility demi animasi.
