# Responsive & Accessibility

## Breakpoints / Test Widths

Wajib diuji di:

- 1440 px
- 1280 px
- 1024 px
- 768 px
- 480 px
- 360 px

## Responsive Rules

### Desktop

- Main question area besar.
- Question Map di kanan.

### Tablet

- Question Map dapat diperkecil.

### Mobile

- Question Map menjadi drawer.
- Timer tetap terlihat.
- Navigation sticky/fixed.
- Jangan ada horizontal scrolling.
- Option mudah disentuh.
- Font nyaman dibaca.

## Accessibility

Pastikan:

- semua button mempunyai focus state;
- keyboard navigation bekerja;
- warna bukan satu-satunya indikator;
- option dapat dipilih dengan keyboard;
- contrast cukup tinggi;
- timer memiliki `aria-label`;
- progress mempunyai `aria-label`;
- modal dapat ditutup dengan keyboard;
- semua input mempunyai label yang jelas;
- heading hierarchy masuk akal;
- elemen interaktif dapat diakses tanpa mouse.
