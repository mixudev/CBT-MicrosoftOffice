# Security, Honesty & README Requirements

## Static Security Reality

Karena seluruh question bank dan logic berada pada client-side JavaScript:

- jangan mengklaim answer key benar-benar aman dari inspeksi browser;
- jangan mengklaim anti-cheating;
- jangan mengklaim setara dengan engine CBT resmi;
- jangan mengklaim sertifikasi;
- jangan mengklaim terhubung ke Microsoft;
- jangan mengklaim terhubung ke TrustTrain.

## Footer

Gunakan:

> Independent practice tool. Not affiliated with Microsoft, Certiport, or TrustTrain.

Tambahkan penjelasan bahwa ini adalah `Practice Simulation` berbasis pilihan ganda.

## README.md

README minimal berisi:

```text
# Microsoft Office 2019 Practice Lab
```

Lalu jelaskan:

- tujuan;
- fitur;
- aplikasi;
- 40 soal per aplikasi;
- timer 50 menit;
- Practice Mode;
- Exam Mode;
- Review Mode;
- localStorage;
- cara menjalankan;
- cara deploy ke Vercel;
- cara deploy ke GitHub Pages;
- disclaimer.

## Running

Tanpa npm adalah preferensi.

Boleh:

- membuka `index.html` langsung;
- atau menjalankan static server sederhana.

## Deployment

Project harus siap diupload ke Vercel sebagai static project atau ke GitHub Pages.
